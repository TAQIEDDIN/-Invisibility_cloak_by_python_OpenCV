# 🪄 Invisibility Cloak with Python + OpenCV

Have you ever dreamed of becoming invisible like Harry Potter?  
With this project, you can simulate **the invisibility cloak** using **Computer Vision** and **Python**! 🚀

---

## ⚙️ Tech Stack
- 🐍 Python  
- 📹 OpenCV (for real-time video processing)  
- 🔢 NumPy (for array operations)  

---

## 💡 How It Works
1. Capture a static background without the person in front of the camera.  
2. Detect the cloak color (in this case **light blue**) using **HSV color space**.  
3. Create a mask for the detected color.  
4. Replace those pixels with the background image.  
5. Result: the cloak blends with the background and the person appears invisible!
